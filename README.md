The program generates:

- Positional frequencies of the 20 individual amino acids
- Positional frequencies of grouped physicochemical categories, including hydrophobic, hydrophilic, and charged amino acids
- A separate report of rejected sequences

Results can be saved in CSV format for subsequent analysis.

## Validation

The program was validated using a dataset of 100 20-amino-acid PRRAR-containing sequence segments of known composition. The calculated positional amino-acid frequencies were compared with the expected frequencies to verify the accuracy of the analysis.

Further details of the validation procedure are provided in **README-AA-Frequency-Analyzer-2.docx**.
